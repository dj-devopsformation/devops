Conteneurisation

La conteneurisation est une technologie qui permet d'isoler et d'exécuter des applications avec toutes leurs dépendances dans un environnement léger et portable appelé "conteneur".

  • ✅ Standardisation des environnements (développement, test, production)
  • ✅ Déploiement rapide et simplifié
  • ✅ Isolation des applications
  • ✅ Utilisation optimisée des ressources système (par rapport aux machines virtuelles)

Outils de Conteneurisation

🔧 Outils Principaux

  • Docker - Plateforme de conteneurisation la plus populaire
  • Podman - Alternative open source à Docker
  • containerd - Runtime de conteneurs par CNCF
  • LXC/LXD - Conteneurs système Linux

📦 Registres d'Images

  • Docker Hub - Registre public officiel Docker
  • Harbor - Registre privé open source par VMware
  • Azure Container Registry - Service Microsoft
  • Amazon ECR - Service AWS

Docker

  • plateforme de conteneurisation qui permet d'empaqueter une application et ses dépendances dans un conteneur léger et portable.
  • Performance : Plus léger et plus rapide que les VM.
  • Portabilité : Fonctionne partout, sans modification.
  • Scalabilité : Déploiement rapide et facile à étendre.

Architecture Docker

DockerFile, Docker Image, et Docker Container

Dockerfile

Un fichier texte contenant les instructions pour construire une image Docker automatiquement.

Instructions Principales

  • FROM : Image de base
  • RUN : Exécuter des commandes
  • COPY/ADD : Copier des fichiers
  • WORKDIR : Répertoire de travail
  • EXPOSE : Exposer des ports
  • CMD/ENTRYPOINT : Commande d'exécution

Commandes

Volumes

  • Les volumes Docker permettent de persister les données même si le conteneur est supprimé.
  • Commandes utiles :

    • docker volume create nom_volume
    • docker run -v nom_volume:/app/data image
    • docker volume ls

Réseaux

  • Docker crée des réseaux virtuels pour connecter les conteneurs entre eux.
  • Types : bridge (par défaut), host, none, overlay (multi-host).
  • Commandes utiles :

    • docker network ls
    • docker network create mon_reseau
    • docker run --network=mon_reseau image

Gestion des Registres Docker

  • Docker Hub : registre public pour partager vos images.
  • Registres privés : Azure Container Registry, Amazon ECR, Harbor, etc.
  • Commandes utiles :
    • docker login : se connecter au registre
    • docker push mon_image : publier une image
    • docker pull mon_image : récupérer une image

Docker Compose

  • Docker Compose permet de gérer plusieurs conteneurs dans un fichier unique docker-compose.yml.
  • Commandes utiles :

    • docker-compose up : démarrer l'application
    • docker-compose up -d --build : démarrer en arrière-plan avec reconstruction des images
    • docker-compose down : arrêter et supprimer les conteneurs
