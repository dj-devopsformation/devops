Problèmes des Multi-Conteneurs

  • Déploiement manuel de chaque conteneur
  • Détection difficile des pannes
  • Récupération manuelle des services
  • Debugging complexe multi-conteneurs
  • Répartition de charge manuelle

La Problématique d'Orchestration

"Docker simplifie le déploiement, mais ne suffit pas pour gérer des centaines de conteneurs microservices. Comment orchestrer tout cela efficacement ?"

Kubernetes

  • plateforme open-source conçue pour automatiser le déploiement, la mise à l'échelle et la gestion des applications conteneurisées.
  • Orchestrer et gérer des conteneurs à grande échelle.
  • Assurer la haute disponibilité des applications.
  • Automatiser la mise à l'échelle et la reprise sur incident.
  • Répartition de charge manuelle

Les Composants Kubernetes

🖥️ Node → héberge les Pods

Machine (physique ou virtuelle) qui exécute les applications.
Un cluster Kubernetes est composé de plusieurs nodes.

📦 Pod → contient les conteneurs

Plus petite unité de déploiement.
Un pod peut contenir un ou plusieurs conteneurs qui partagent le même réseau et stockage.

🌐 Service → expose les Pods

Permet d'accéder aux Pods via une adresse IP stable.
Assure l'équilibrage de charge et la communication interne/externe.

🔁 Deployment → gère le déploiement et l'évolution

Automatisation de la création, mise à l'échelle et mise à jour des Pods.
Supporte les rolling updates et les rollbacks pour des mises à jour sans interruption.

kubectl Commandes

📋 Commandes de Base

  • kubectl get pods - Lister les pods
  • kubectl get services - Lister les services
  • kubectl get deployments - Lister les déploiements
  • kubectl get nodes - Lister les nodes
  • kubectl describe pod [nom] - Détails d'un pod

🚀 Commandes de Déploiement

  • kubectl apply -f fichier.yaml - Appliquer un fichier
  • kubectl create deployment [nom] --image=[image] - Créer un déploiement
  • kubectl scale deployment [nom] --replicas=3 - Mettre à l'échelle
  • kubectl rollout status deployment/[nom] - Statut du déploiement
  • kubectl rollout undo deployment/[nom] - Annuler un déploiement

🔧 Commandes de Debug

  • kubectl logs [pod] - Voir les logs
  • kubectl exec -it [pod] -- /bin/bash - Accès shell
  • kubectl port-forward [pod] 8080:80 - Port forwarding
  • kubectl get events - Voir les événements
  • kubectl top pods - Utilisation des ressources
  • kubectl config view - Configuration
